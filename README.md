# AutoPodcastor

把已有台本制作成个人播客的 Android 应用。此仓库提供安装包和应用内更新清单。

[下载最新版](https://github.com/slowpoke0520/AutoPodcastor/releases/latest)

安装要求：Android 10 或以上、ARM64。当前是开发版，包名和签名沿用旧版。

已装 0.3.0 或以上可在“设置 → 应用更新”检查和升级；也可下载 APK 直接覆盖安装。不要先卸载或清除数据。系统可能要求允许此来源安装应用，也支持在软件中选择本地新版 APK。

当前 0.6.0 提供单人/双人制作、角色独立声音、A/B 试听缓存，以及片段拆分、合并、换角色、局部风格和重做。生成前确认范围，只制作本次调整的片段；保存新版本不调用 TTS，旧版本和音频可以回听。

长台本在正文框内滚动，预览、保存和制作按钮固定在底部。自定义风格支持自然语言说明和开头的 `（低语）`、`[兴奋]` 等标签；采用逐段完整 WAV 生成，普通预设继续流式生成。改变风格需制作新音频才能听到变化。

MiMo API Key 由用户在手机内填写，存入设备安全存储。发布包和更新清单不包含用户 Key、台本或音频。

本地自动化与 MuMu 模拟器验证不替代 Android 真机验收。分段听感需要实际试听；跨段等待仍待优化，长节目、完整系统音频路由和 M4A 导出在后续阶段。各阶段验收后再继续。
